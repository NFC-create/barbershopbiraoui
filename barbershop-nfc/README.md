# Barber Biraoui — landing page NFC

Site statique mobile-first en HTML, CSS et JavaScript. Aucune installation ni dépendance n’est nécessaire.

## Ouvrir dans IntelliJ IDEA

1. Ouvrez le dossier `barbershop-nfc` dans IntelliJ IDEA.
2. Ouvrez `index.html`.
3. Cliquez sur l’icône du navigateur, ou faites clic droit puis **Open in Browser**.

Le site fonctionne aussi par double-clic sur `index.html`.

## Publier sur GitHub Pages

1. Créez un dépôt GitHub vide.
2. Ajoutez le contenu du dossier `barbershop-nfc` à la racine du dépôt, puis validez les fichiers.
3. Dans **Settings → Pages**, choisissez **Deploy from a branch**, la branche `main`, puis le dossier `/ (root)`.

## Publier sur Vercel

1. Importez le dépôt GitHub dans Vercel.
2. Choisissez **Other** comme framework.
3. Laissez la commande de build vide et utilisez `.` comme dossier de sortie.
4. Lancez le déploiement.

Après attribution du domaine final, utilisez son URL HTTPS complète dans la balise `og:image` de `index.html` pour garantir l’aperçu sur tous les réseaux sociaux.
